| 5.2 Товары и остатки | Build: кабинет + Partner: WhatsApp BSP | Продавцы без кабинета (ЦБ) | BSP \$100/мес | - |
| 5.3 Аналитика продавца | Build, 12 мес | Не нужна для первой продажи | ФОТ | - |
| 6.1 Аккаунт | Build: сервис ПДн | Локализация ПДн ([ADR-003](../Task4/adr-003-data-residency.md)) | ~\$120/мес | - |

| 6.4 Поддержка и споры | Build в бэк-офисе | SaaS-хелпдеск вывез бы ПДн Нигерии | ФОТ | - |

| 7.2 Антифрод | Buy: инструменты провайдера + Build лимиты | ML без данных бесполезен | \$0 | Фрод на возвратах |
| 7.3 Аналитика и дашборд | Build на реплике БД | Дашборд запуска (А2) | \$0 | - |
| 8.1 Клиентские каналы | Build: Android, веб | Ядро продукта | ФОТ | Ревью Google Play к 1.10 |
| 8.2 Хостинг, БД, очередь | Buy: AWS managed | ADR-001 | ~\$1 020/мес | - |
| 8.3 Наблюдаемость | Buy: Grafana Cloud | Без своего стека | \$150/мес | - |
| 8.4 CI/CD | Buy: GitHub | - | \$100/мес | - |

Итого: 
- Build - ядро продукта и всё, что держит закон и деньги. 
- Partner - платежи, доставка, каналы связи. 
- Buy - инфраструктура.

## 3. Предложения CTO (А5): расчёт

Ставка контрактора \$60k/год (TCO).

**Своя логистика - отклонено на MVP, пересмотр на месяце 12.**

| | Build | Partner |
|---|---|---|
| Разработка | 4 инженера × 6 мес = \$120k | 0 |
| Сопровождение | 2 инженера = \$120k/год | 0 |
| Готовность | февраль 2027 | 15.10.2026 |
| Цена срыва 15.10 | \$180k рекламы не возвращается (А2) | 0 |
| Плата за API, Год 1 | 0 | \$0,15 × 1,2M = \$180k |
| Курьеры, ПВЗ, страховка | Не оценены, наши | У партнёра |

- Год 1: build \$420k без курьеров против \$180k у партнёра.
- Месяц 12: 250k заказов/мес, плата партнёру \$37,5k/мес против \$10k/мес на свою команду диспетчеризации. С этого объёма есть смысл в своей диспетчеризации в Лагосе и Найроби. Решение принимаем по фактической себестоимости курьера.

**Своя платёжная оркестрация - отклонено, строим тонкий слой маршрутизации.**

- Прямой эквайринг требует лицензии, в срок нереалистично (А3).
- Без лицензии оркестрация не снижает ставку: её задают провайдеры.
- Единственная прямая интеграция с экономией - M-Pesa в Кении, 0,55% вместо 1,5-2,9% ([ADR-004](adr-004-payment-provider.md)). Это договор с Safaricom, а не своя оркестрация.
- Своя оркестрация: 2 инженера = \$120k/год. Окупается при экономии 0,3 п.п. на GMV от \$40M/год (Год 2) и только при наличии лицензии.
