# SLO: Каталог

**Сервис:** модуль `catalog` монолита + CDN
**Владелец:** команда ядра, дежурный по ротации
**Окно:** скользящее, 28 дней
**Связано:** NFR-01, NFR-05, NFR-06, NFR-09 ([реестр НФТ](../nfr-registry.md)), [ADR-002](../adr-002-caching-strategy.md)

---

## SLI

| SLI | Что считается хорошим событием | Источник данных |
|---|---|---|
| Доступность | Ответ на `GET /catalog/*` и `GET /products/*` без 5xx и не дольше 3 с. Ответ CDN из кеша, включая stale, считается успешным | Логи CDN + метрики origin |
| Задержка origin | Ответ origin быстрее порога | Гистограмма `http_server_duration` (OpenTelemetry) |
| Время до первого товара | Первая карточка на экране быстрее порога | RUM в мобильном приложении |
| Свежесть | Цена и остаток в карточке обновились после изменения продавцом | Метка времени события и время отдачи |

## SLO

| SLI | Цель | Бюджет ошибок за 28 дней |
|---|---|---|
| Доступность | 99,9% | 40 мин или 0,1% запросов |
| Задержка origin | • 95% ≤ 300 мс<br><br>• 99% ≤ 800 мс | 1% запросов медленнее 800 мс |
| Время до первого товара | • 90% сессий ≤ 2 с на 4G<br><br>• 90% сессий ≤ 4 с на 3G | 10% сессий |
| Свежесть | 99% изменений видны ≤ 60 с | 1% изменений |

## SLA

Внешнего SLA с компенсацией в MVP нет. Обязательства перед бизнесом:

| Кому | Что гарантируется | Что при нарушении |
|---|---|---|
| Инвестор, маркетинг | Каталог доступен во время рекламы и стримов (А2) | • Расход 50% бюджета за неделю: заморозка фич, только исправления надёжности<br><br>• Постмортем за 48 ч |
| Продавцы | Товар после модерации виден в каталоге ≤ 5 мин | Ручная публикация оператором, разбор причины |
| Покупатели | Цена в корзине равна цене при оплате | Цена при оплате берётся из БД, а не из кеша. Расхождение - в пользу покупателя |

## OpenSLO

```yaml
apiVersion: openslo/v1
kind: SLO
metadata:
  name: catalog-availability
  displayName: Каталог - доступность
spec:
  service: catalog
  indicator:
    metadata:
      name: catalog-good-requests
    spec:
      ratioMetric:
        counter: true
        good:
          metricSource:
            type: Prometheus
            spec:
              query: sum(rate(catalog_requests_total{code!~"5..",slow="false"}[5m]))
        total:
          metricSource:
            type: Prometheus
            spec:
              query: sum(rate(catalog_requests_total[5m]))
  timeWindow:
    - duration: 28d
      isRolling: true
  budgetingMethod: Occurrences
  objectives:
    - displayName: 99,9% успешных запросов
      target: 0.999
```

## Допущения

- Метрика `catalog_requests_total` объединяет логи CDN и origin, метка `slow` ставится при ответе дольше 3 с.
- 3G и 4G различаются по типу сети, который сообщает Android.
