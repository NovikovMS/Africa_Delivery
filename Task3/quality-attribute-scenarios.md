# Quality Attribute Scenarios

**Версия:** 1.0
**Дата:** 25.08.2026
**Связано:** [реестр НФТ](nfr-registry.md), [FMEA](fmea.md)

Поля сценария: источник, стимул, артефакт, среда, отклик, мера отклика.

## Допущения

- Нагрузка QAS-03 и QAS-04 - из расчёта в разделе «Допущения» [реестра НФТ](nfr-registry.md).
- Paystack подключён как резервный провайдер для Нигерии (ADR-001). В Кении резерва для M-Pesa нет: при сбое заказ ждёт оплату в очереди.
